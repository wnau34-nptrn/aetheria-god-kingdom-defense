# บันทึกการเล่น AETHERIA และการประเมินใหม่

## สิ่งที่เปลี่ยนจากข้อสรุปรอบแรก

เกมมีระบบเชื่อมกันมากกว่าที่ smoke test รอบแรกแสดง การพัฒนาต่อควรเริ่มจากทำความเข้าใจและปรับระบบเดิม ก่อนเพิ่มกลไกใหม่ โดยเฉพาะสิ่งเหล่านี้มีอยู่แล้วและรอบนี้เห็นผลจากการเล่นจริง:

- เก็บของ → แบกกลับคลัง → เมืองเริ่มก่อสร้าง → คนเดินไปสร้างจนเสร็จ
- ความหิวแทรกงานขนของ/ผลิต และทำให้พลเรือนออกจากที่พักกลางคืน
- การใช้ศรัทธาร่วมกันระหว่างฝน เสกคน แต่งตั้งทหาร ป้อม และพลังโจมตี
- การวางป้อมผ่านพรลำแสง พร้อมฟื้นคน; สายฟ้า/อุกกาบาตมีผลต่างกันและอุกกาบาตมีลูกหลง
- เหตุการณ์เปลี่ยนบ้าน คน กองทัพ รถม้า ทรัพยากร ความก้าวหน้า และ Max HP อาคารจริง
- อาชีพใหม่และเศรษฐกิจเปลี่ยนตามยุค ไม่ใช่เพียงเปลี่ยนโมเดลอาคาร

ข้อเสนอเดิมที่ให้เพิ่ม placement, ศัตรูเร็ว/ถึก/แม่ทัพ และตัวเลือกเศรษฐกิจกับการป้องกันซ้ำ ถูกแก้ใน AUDIT และ ROADMAP แล้ว วิหารที่คุ้มครองเมืองและเกมที่เล่นต่อได้เมื่อคนหมดควรถูกมองเป็นกติกา sandbox ที่ต้องยืนยันเจตนา ไม่ใช่บั๊กที่ต้องรีบเปลี่ยนเป็น game-over

## วิธีเล่นและขอบเขต

เล่นไฟล์ HTML ต้นฉบับที่เก็บไว้ใน `original/` ผ่าน Chromium + ANGLE/SwiftShader เป็น session ต่อเนื่อง **1,503 วินาที หรือประมาณ 25 นาที** บันทึก 606 snapshots และ input 119 รายการ (รวมปุ่ม กล้อง screenshot และคำสั่งจบ session) ที่ viewport 640×480

การเปลี่ยนเกมใช้การคลิก/คีย์บอร์ดบน UI ผ่าน Playwright เท่านั้น ใช้ `AETHERIA_API` อ่านข้อมูลประกอบการสังเกต ไม่เรียกฟังก์ชันเสกพลัง สร้างศัตรู เปลี่ยนยุค หรือเขียน resources/time/state ผ่าน API ไม่มีการแก้ renderer หรือข้าม animation เพื่อเร่ง simulation

แบ่งเส้นทางให้ชัด:

1. จากเริ่มเกาะ ผ่านงานเมือง กลางคืน เวฟหนุน รุ่งอรุณ ฟื้นประชากร และ **ขึ้นยุค 2 ตาม progress จริง** ใช้ปุ่มเร่งเวลา 5x ที่เกมมีให้ ไม่กดปุ่มเลือกยุค/ข้ามวันคืนช่วงนี้
2. หลังขึ้นยุค 2 ใช้ปุ่มเรียกเหตุการณ์และแท็บเพื่อสำรวจผลทางเลือกที่ยังไม่เจอเอง เหตุการณ์เสบียงแรกเกิดเอง ส่วนคำสั่งทหารในคืนแรกถูกเรียกจากปุ่มเพื่อแทรกแซงศึก
3. ยุค 3 และ 4 ใช้ปุ่มเลือกยุคใน UI เป็นการสำรวจแยก ไม่ได้เล่นเก็บ progress จนถึงยุค 4
4. ตอนท้ายใช้ปุ่มกลางคืนขณะ pause เพื่อดูคลื่นศัตรูยุค 4 และบันทึก checkpoint ไม่ใช่ผลการรอดคืนยุค 4

ยังไม่ได้ทดลองครบทุกทางเลือกทั้ง 15 ข้อ เล่นจริง 6 ทางเลือกครอบคลุม 5 กลุ่มเหตุการณ์ ยุค 3–4 มีเวลาสำรวจสั้นกว่ายุค 1–2 และไม่มีหลาย run สำหรับสรุปสมดุล

## สิ่งที่เข้าใจจากการเล่น

### เศรษฐกิจเดิมมีขั้นตอนและจังหวะสะดุดที่มีเหตุผล

การเห็นของเพิ่มช้าบน HUD ไม่ได้แปลว่า AI ไม่ทำงาน ต้องดูของที่แบก ระยะทาง สะพาน ความหิว และงานสร้างที่แทรกเข้ามา เหตุการณ์เลี้ยงเมืองทำให้แรงงานหลายคนกลับจาก FORAGE ไป HAUL จึงมีผลมากกว่าการเติมตัวเลขอาหาร

ยุค 2 อาหารเพิ่มจากชาวนากับชาวประมงโดยมี state ทำงานจริง ยุค 3 พ่อค้าเข้าสู่ MARKET และศรัทธาเพิ่มตามกิจกรรม เมื่อรวมกับทรัพยากรเดิมและเหตุการณ์ เศรษฐกิจจึงเปลี่ยนตามยุค ควรวัดอัตราเหล่านี้ก่อนเพิ่ม production chain ใหม่

### ผู้เล่นมีเครื่องมือแทรกแซงหลายระดับอยู่แล้ว

มีทั้งแก้เฉพาะพื้นที่ด้วยฝน/เวท เลือกพื้นที่ป้อม เพิ่มแรงงานหรือทหาร และเปลี่ยนเมืองผ่านคำตัดสิน เหตุการณ์ทหารโจมตีทั้งแผนที่ต่างจากสายฟ้าเล็งจุด อุกกาบาตทำลายได้มากแต่มีลูกหลง พรป้อมฟื้นคนร่วมด้วย ควรทำให้ผู้เล่นอ่านความต่างนี้ได้ง่ายขึ้น

### ความต่อเนื่องข้ามยุคเป็นประเด็นที่ต้องยืนยันเจตนา

หลังฟื้นคน 2 คนด้วยศรัทธา ยุค 2 เปลี่ยนเป็นคนชุดใหม่ 14 คน เช่นเดียวกับการกดสำรวจยุค 3 ที่เปลี่ยนชุดเมืองและล้างศัตรูที่ยังอยู่ โบนัส Max HP +50 จากเหตุการณ์ก่อนหน้าก็ไม่ได้บวกต่อเหนือค่าเริ่มต้นยุคใหม่ นี่อาจเป็นการออกแบบ showcase/sandbox แต่ถ้าตั้งใจให้ผูกพันกับชาวบ้านและลงทุนระยะยาว ต้องตกลงความต่อเนื่องก่อน refactor หรือทำ full save

### ความสูญเสียไม่ได้หมายความว่าการเล่นต้องจบ

run นี้เสียประชากรทั้งหมดแล้วเสกกลับมาได้ ก่อนที่การพัฒนายุคจะสร้างเมืองชุดใหม่ วิหารคุ้มครองเมืองทำให้เกิดการกู้สถานการณ์ การบังคับเพิ่ม game-over ทันทีอาจเปลี่ยนเจตนานี้ จึงควรถามทิศทางโหมดก่อน

## ประเด็นที่ควรตรวจต่อโดยไม่เพิ่มระบบซ้ำ

1. เทียบต่อสู้ 1x/5x ในเวอร์ชันที่แก้ฐานเวลาแล้วหลาย run รอบนี้เล่นต้นฉบับที่กระสุนเคลื่อนตาม rawDt แต่ยูนิต/การโจมตีเร่งตาม timeScale จึงใช้ผลคืนแรกฟันธงสมดุลไม่ได้ อีกทั้ง run นี้สุ่มแม่ทัพมากและการตอบสนองผ่านเครื่องมือไม่ใช่การเล่นของคนทั่วไป
2. อธิบายข้อจำกัดพื้นที่วางป้อม/ปั้นดินให้เฉพาะเจาะจงขึ้น เช่น ถนน พื้นสูง/ชัน หรือระยะฐานอาคาร ผู้เล่นมี preview อยู่แล้ว แต่ข้อความปฏิเสธยังรวมหลายสาเหตุ
3. กำหนดว่าอะไรต้องคงอยู่เมื่อพัฒนายุค และแยกปุ่มสำรวจ/สลับยุคจากความก้าวหน้าหลักถ้าจะมีโหมด challenge
4. ตรวจข้อความเล่าเรื่องกับ simulation: รถม้า/สัตว์/บอลลูนทำให้ฉากมีชีวิต แต่ยังไม่พบ cargo inventory หรือปศุสัตว์ผลิตของจากโค้ดที่ตรวจ ไม่จำเป็นต้องเพิ่มระบบเหล่านี้หากตั้งใจเป็นองค์ประกอบฉาก
5. ทดสอบเซฟโลกและการฟื้นเมืองต่อเนื่อง ปุ่มเซฟมีอยู่แล้ว แต่ checkpoint V1 ไม่รักษาสภาพเกาะ/คน/อาคาร/ศึกทั้งหมด
