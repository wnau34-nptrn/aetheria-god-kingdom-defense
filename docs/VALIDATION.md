# Validation evidence

Validated on 15 October 2026 in Linux Chromium using ANGLE/SwiftShader. Desktop test viewport: 1280 × 800. Mobile emulation: 390 × 844, touch enabled, device scale factor 1. The original desktop reference uses 1440 × 900.

## Automated checks

- `npm test`: checkpoint parsing accepts V1/zero resources, rejects malformed/incomplete/out-of-range/non-finite values, and ignores unknown fields.
- Renderer unit cases verify 32-bit indices are retained above vertex 65,535, small meshes use 16-bit indices, and unsupported large meshes fail explicitly.
- `npm run build`: static production output generated by Vite.
- `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser`: three browser scenarios cover startup, compact-desktop HUD separation, pause through dilemma tab switches, frozen monster health/time/projectile positions, progression gating, era change, save/reload, storage failure feedback, a single touch rain cast costing exactly 15 faith, mobile HUD viewport bounds, and visible failure when WebGL is absent.
- Original uploaded HTML SHA-256 matches `source-provenance.json`.
- `node --check` on extracted game/renderer and `git diff --check`.

The first desktop test run timed out because a 960px viewport intentionally hides the side panel containing the advance-era button. Corrected the test to a desktop viewport and reran. This was test setup, not a game crash.

## Additional smoke pass

`tests/inspect-current.mjs` exercises era 3 and era 4, calls rain/terraform/lightning/miracle, resets camera, and triggers a nighttime wave. `additional-smoke.json` records populations of 23/29, building counts of 19/22, successful camera reset, and 13 spawned monsters with no uncaught page errors. This confirms basic execution, not long-run balance or complete spell-effect correctness.

With the dev server running, repeat audit scripts using:

```bash
CHROMIUM_PATH=/usr/bin/chromium npm run audit:current
CHROMIUM_PATH=/usr/bin/chromium npm run audit:original
```

Omit `CHROMIUM_PATH` to use a Playwright-installed Chromium. The original audit intentionally reproduces bugs in the preserved upload. Raw observations from the initial original pass are in `original-observations.json`; its first mobile image was taken during a resize/HUD transition, so use the stable current mobile screenshot to judge viewport coverage. Original resource console 404s were observed; no uncaught page errors were recorded.

## Limits

No hardware GPU FPS benchmark, SpectorJS capture, real iOS/Android or Safari test, 30-minute soak, full economy balance pass, or comprehensive GPU memory measurement was performed. Full world save is not implemented. CI is configured for future pushes; local results do not claim that GitHub Actions has already passed.
