# พัฒนายุคโดยรักษาเมืองเดิม — P0a

## พฤติกรรมที่เปลี่ยน

ใช้ **พัฒนายุค** บนแถบคำสั่งหลักเมื่อความก้าวหน้า 100% เพื่อพัฒนาไปทีละยุค ความเร็ว 1x/2.5x/5x เร่งเวลาเท่านั้น ไม่เลือกยุคแทนผู้เล่น ปุ่มพร้อมกดทันทีเมื่อ progress เต็ม

การพัฒนาปกติรักษาคน อาคาร ธรรมชาติ ภูมิประเทศที่ปั้น งาน/cargo/ความหิว การเลือกและติดตามยูนิต ศัตรู เวฟ กระสุน และจังหวะต่อสู้เดิม ไม่สร้างประชากร บ้าน ป้อม ไร่ หรือตลาดชุดใหม่แทนสิ่งที่ผู้เล่นลงทุน

ยุคใหม่เพิ่มเพดานบ้าน/ป้อมและรูปแบบอาคารที่สร้างหลังจากนั้น ถนนเปลี่ยนสีตามยุค อาคารเดิมเก็บรูปลักษณ์ ยุคที่สร้าง HP/maxHP โบนัสเสริมเกราะ และความคืบหน้าก่อสร้างไว้ ไม่ได้รับการซ่อมหรือเพิ่มเลือดฟรีจากการกดขึ้นยุค การอัปเกรดอาคารเป็นระบบที่จะทำต่อภายหลัง

## แยกจาก sandbox

ในเมนู **เครื่องมือโลกและยุค** ปุ่ม **ฉากยุค 1–4** ยังคงสร้างเมืองตัวอย่างของยุคนั้นแทนเมือง/ยูนิตเดิม พร้อมข้อความอธิบายผล การสุ่มเกาะใหม่ยังเริ่มโลกใหม่ ทั้งสองอย่างเป็นเครื่องมือ sandbox ไม่ใช่เส้นทางพัฒนาเมืองปกติ

V1 checkpoint เดิมยังโหลดทรัพยากร/วันเวลา/ยุคและสร้างฉากของยุคที่บันทึกตามขอบเขตเดิม **ยังไม่ใช่การคืนเมือง อาคาร และคนเดิมหลัง reload** งานนี้คือ P0a; World Save V2/autosave อยู่ P0b

## ข้อมูลและ AI

- `progression.js` ถือกติกาความพร้อม/ยุคถัดไป ไม่มี mesh/DOM และไม่รู้ความเร็วภาพ
- `advanceEra()` ใช้กติกาปกติ ไม่เรียก `populateWorld()` ส่วน `previewEra()` เป็นเส้นทางสร้างฉาก sandbox; `evolveToEra` ใน development API เป็น compatibility alias ของ preview สำหรับ fixture เดิมเท่านั้น
- selectable entities มี `entityId` ที่เป็น string, serialize ได้ และไม่เปลี่ยนระหว่าง session แยกจาก numeric `agent.id` ที่ AI/ชื่อเดิมใช้ ตัวนับไม่เริ่มใหม่ระหว่าง preview/regenerate จึงไม่ซ้ำกับวัตถุเก่าใน session นี้ การคืน ID จากเซฟข้าม session เป็นงาน P0b
- บ้าน/ป้อม/วิหารมี `era` ที่สร้างไว้ในข้อมูล ไม่อนุมานว่าทุกอาคารมีอายุเท่ายุคเมืองล่าสุด
- เส้นทางและพื้นที่เดินบนสะพานใช้รายการสะพานที่สร้างจริง ขึ้นยุค 3 ไม่ทำให้ AI คิดว่ามีสะพานเหนือฟรี พื้นที่บ่อน้ำ/คอกสัตว์สงวนเมื่อมีสิ่งนั้นจริงเท่านั้น
- งานหาแหล่ง/ขน/สร้าง/ซ่อมและการหลบภัยกลางคืนยังเป็น AI เดิม งานความปลอดภัยตามพื้นที่และคำสั่งทหาร/HUD เมือง–รบยังอยู่ P1

## การตรวจ

- `tests/progression.test.js`: กติกายุค/identity, เมืองที่ลงทุนและงานค้างครบถึงยุค 4, terrain/cargo/HP/โบนัส/selection/เวฟ/กระสุน, 1x/2.5x/5x, strike ที่เริ่มแล้ว, การส่งแร่ผ่านสะพานที่มีจริง, อาคารใหม่ตามยุค และ sandbox reset
- `tests/progression.spec.js`: WebGL/ปุ่มจริง desktop และ touch viewport ใช้ starting fixture ใกล้พร้อมขึ้นยุค/อาคารเสียหาย/ของที่คนแบก กดพัฒนาครบสามครั้งและเทียบ object เดิม ก่อนใช้ sandbox สร้างฉากใหม่ ไม่อ้างว่าเป็นการเล่นธรรมชาติครบสี่ยุค
- regression เดิมครอบคลุมการเดิน เศรษฐกิจ ต่อสู้ เวลา เหตุการณ์ และ checkpoint CI ตรวจ production subpath และเว็บ Pages ตาม commit ที่เผยแพร่
