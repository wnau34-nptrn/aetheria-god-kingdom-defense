# แผนพัฒนา AETHERIA — เมืองอัตโนมัติและสงคราม RTS

ปรับวันที่ 18 ตุลาคม 2026 จาก commit `7bd3f97beb381e4b24ca5550eb981727c1db5465` ดู [ผลตรวจระบบปัจจุบัน](CURRENT_REVIEW.th.md) สำหรับข้อเท็จจริงและวิธีตรวจ ด้านล่างเป็นแผนอนาคต ยกเว้นรายการที่ระบุว่ามีแล้ว ไม่ใช่ฟีเจอร์ที่เผยแพร่แล้ว และไม่ใช่การรับปากระยะเวลาส่ง

## เป้าหมายและหลักการ

ผู้เล่นพัฒนาอารยธรรมบนเกาะลอยฟ้า วางนโยบายเมือง บัญชาการกองทัพ และใช้พลังเทพ AI เดินทาง ผลิต ขนส่ง ก่อสร้าง ฝึก และปฏิบัติตามคำสั่ง ช่วงปลอดภัยเน้นพัฒนาเมือง ช่วงมีภัยเน้นบัญชาการ ทั้งสองด้านใช้ simulation เดียวกันตลอด

- ผู้เล่นเลือกว่าจะทำอะไร และเลือกตำแหน่งเมื่อจำเป็น เช่น อาคารหรือแนวรับ AI เลือกแหล่งทรัพยากร เส้นทาง และเป้าหมายย่อยเอง
- HUD เปลี่ยนตามสถานการณ์โดยไม่หยุดเวลา ไม่ล้างคำสั่ง ไม่กระชากกล้อง สลับเมือง/รบเองได้เสมอ คำสั่งสำคัญ การฝึก และคำตอบเหตุการณ์เข้าถึงได้ทันที
- ความปลอดภัยพิจารณาภัยในพื้นที่ กลางคืนยังมีผลต่อแสง/เวฟ แต่ไม่หยุดเศรษฐกิจทั้งเกาะเพียงเพราะเป็นกลางคืน
- เมือง คน ประสบการณ์ อาคาร และการลงทุนต่อเนื่องเมื่อขึ้นยุคและกลับเข้าเกม
- หน่วย/ยานใหม่มีหน้าที่ ข้อจำกัด และการตอบโต้ ใช้ทรัพยากรเดิมให้มีความหมายก่อนเพิ่มวัตถุดิบใหม่
- คงการฟื้นเมืองและเกราะวิหารของ sandbox เดิม โหมดแพ้/ชนะถาวรเป็นงานแยกภายหลัง

## ฐานที่มีแล้วและต้องใช้ต่อ

มีเกาะ procedural/ปั้นพื้น แม่น้ำ/สะพาน กลางวัน–คืน ทรัพยากรสี่ชนิด การขนเข้าคลัง บ้าน/ป้อมที่คนงานสร้างและซ่อม อาชีพพลเรือนหลายแบบ ทหารประชิดหนึ่งประเภท อสูรเร็ว/ถึก/แม่ทัพ ป้อมยิงอัตโนมัติ พลังเทพ เหตุการณ์ห้ากลุ่ม กล้อง/แผนที่/ข้อมูลยูนิต และสี่ยุคเดิม

มี fixed-step 50ms คำสั่งคนงานให้ AI หาแหล่งเอง ปุ่มหลักหกปุ่มพร้อมราคา คำตอบเหตุการณ์ทันที และจังหวะโจมตีเตรียม–ปะทะ–คืนท่าแล้ว ใช้เป็นฐาน ไม่ทำซ้ำจากศูนย์

## P0 — ความต่อเนื่องของเมืองและโลก

แบ่งส่งเป็น **P0a: แก้การขึ้นยุค/เวลาและวางข้อมูลตัวตน (ข้อ 1–3)** กับ **P0b: เซฟโลก (ข้อ 4–5)** เริ่มคำสั่ง/HUD ของ P1 หลัง P0a ได้ระหว่างทำ P0b แต่ต้องเสร็จทั้งสองตอนก่อนปล่อยระบบฝึกสะสมและวิจัยใน P2–P3

1. แยก **พัฒนายุคในเกมปกติ** ออกจาก **สร้างฉากตัวอย่างของยุคใน sandbox** ไม่ให้ progression เรียก `populateWorld()` ล้างเมืองทั้งชุด
2. เอาการขึ้นยุคอัตโนมัติที่ผูกกับความเร็ว 5x ออกจากการเล่นปกติ ความเร็วเร่ง simulation เท่านั้น การพัฒนาเกิดจากคำสั่ง/เงื่อนไขที่ผู้เล่นเห็น
3. กำหนด entity IDs และข้อมูลที่บันทึกได้ แยกข้อมูลยูนิต/คำสั่งจาก mesh ทีละระบบ ไม่เขียน simulation ใหม่ทั้งหมดในรอบเดียว
4. ทำ World Save V2: seed/terrain edits, วันเวลา/คลื่น/ตัวจับเวลา, RNG, ทรัพยากร/cargo, อาคาร/HP/งานค้าง, ยูนิต/ความหิว/งาน/คำสั่ง และสถานะศัตรู/การโจมตี/กระสุนที่จำเป็นต่อการคืนศึกเดิม เพิ่มข้อมูลฝึก/วิจัยเมื่อมี P2–P3
5. โหลด V1 เป็น checkpoint โดยระบุว่าไม่ได้คืนโลกเดิม ตรวจข้อมูลก่อนเปลี่ยนโลก สำรองข้อมูลก่อน overwrite เพิ่ม autosave หลัง snapshot ผ่านการตรวจ

เกณฑ์รับ:

- สร้างบ้าน สั่งงาน แต่งตั้งทหาร ทำอาคารเสียหาย → ขึ้นยุค: ตำแหน่ง ตัวตน งาน cargo HP และสิ่งที่ลงทุนยังอยู่ การเพิ่ม max HP มีกติกาอัปเกรดชัดเจน
- save/reload ทั้งยามสงบและกลางศึกได้โลกเดิม เซฟเสียไม่ทำลาย session ปัจจุบัน
- seed/คำสั่งเดียวกันที่ 1x/2.5x/5x ให้ผล simulation เทียบกันได้ ความเร็วไม่เลือกยุคแทนผู้เล่น

## P1 — สั่งกองทัพ + HUD เมือง/รบ + AI รับมือภัย

ชุดเล่นได้แรกหลัง P0a ใช้ทหารประชิดและอสูรเดิมก่อน ทำคู่กับ World Save P0b ได้ โดยยังระบุขอบเขต checkpoint เดิมจนกว่าเซฟโลกจะพร้อม

**คำสั่ง:** เลือกหนึ่งหน่วย/ทั้งกอง → รวมพล, เคลื่อนพล, ตั้งรับจุดนี้, โจมตีพื้นที่, ถอยกลับฐาน และคืน AI อัตโนมัติ มีวงเลือก จุดหมายและสถานะตอบรับ ใช้ปุ่มแล้วแตะพื้นได้ทั้งเมาส์/สัมผัส รักษาการหมุน/เลื่อนกล้องเดิม ไม่บังคับลากครอบเพื่อออกคำสั่งพื้นฐาน

**AI ทหาร:** ตั้งรับมีพื้นที่รับผิดชอบ/ระยะไล่ตามและกลับประจำจุด ไม่ถูกพฤติกรรมไล่ศัตรูทั่วเกาะตอนกลางคืนเขียนทับ ถอยสำคัญกว่าหาเป้าหมายใหม่ กำหนดวิธีรับคำสั่งระหว่างท่าที่เริ่มแล้วโดยไม่ตัด/ทำซ้ำ damage จัดตำแหน่งอย่างง่ายและคิวผ่านสะพาน ไม่ตั้งหน่วยในจุดเดินไม่ถึง

**การอ่านสนาม:** แจ้งจุดถูกโจมตี/แนวแตก/วิหารเสียหาย กดเพื่อไปตำแหน่งนั้นได้ ใช้ jump battle และ minimap เดิมต่อยอด มีทางกลับมุมเมือง โดยเฉพาะมือถือที่แนวปะทะอาจอยู่นอกจอเริ่มต้น ไม่ย้ายกล้องเองเมื่อสลับ HUD

**HUD:** ใช้เวฟและอสูรที่ยังมีชีวิตกำหนดเตรียมรับภัย/มีภัย/ฟื้นเมือง รวมอสูรจากศิลากลางวัน รักษาหน้ารบถ้ายังมีภัยหลังรุ่งเช้า แยกรอทัพหนุนจากจบศึกจริง และป้องกันสลับแถบไปมาทุกเฟรม

| สถานการณ์ | เนื้อหาหลัก | สิ่งที่เข้าถึงได้เสมอ |
|---|---|---|
| พัฒนาเมือง | คน/ที่พัก แรงงาน สต็อก/cargo ก่อสร้าง ความก้าวหน้า | เวลา กล้อง พลังเทพ เตรียมกองทัพ |
| เตรียมบุก | เวลาถึงเวฟ กำลังพร้อมรบ จุดรวมพล แนวรับ | ฝึก/จ้างทหาร ทรัพยากร เสริมป้อม |
| การรบ | กองที่เลือก คำสั่ง วิหาร/อาคารถูกตี อสูร พลังเทพและราคา | เสริมกำลัง สลับเมือง ทรัพยากร คำตอบเหตุการณ์ |
| ฟื้นเมือง | ความสูญเสีย อาคารเสียหาย งานซ่อม กำลังผลิตที่ขาด | กลับสั่งรบเมื่อมีภัยใหม่ |

**AI พลเรือน:** พื้นที่อันตรายหยุดงาน/หาที่ปลอดภัย พื้นที่ปลอดภัยยังผลิต/ขน/สร้าง เก็บคำสั่งและ cargo ระหว่างหนี แล้วกลับงานหลังภัยผ่าน มีช่วงรอก่อนกลับเพื่อไม่วิ่งสลับ ความหิวไม่ดึงคนออกจากที่ปลอดภัยเข้าหาอสูร เหตุการณ์ย่อเข้ามาโดยไม่บังคับหยุดเวลา/ย้ายกล้อง ผู้เล่นยังพักหรือเปิดเรื่องเต็มได้

เกณฑ์รับ:

- กลางวันสั่งตั้งรับ → ค่ำ → ศัตรูเข้าระยะ → สกัดและกลับแนวเดิม; สั่งถอยแล้วไม่วิ่งกลับไปหาอสูร
- มีของส่งคลังจากพื้นที่ปลอดภัยขณะอีกพื้นที่รบ คนหนีรักษา cargo/งานเดิมแล้วกลับทำต่อ
- อสูรจากศิลากลางวันเปิดหน้ารบ รุ่งเช้าที่ยังมีศัตรูไม่ปิดหน้ารบก่อนเวลา รอทัพหนุนไม่สรุปจบศึก
- ปุ่มเมือง/รบและคำตอบสามข้อกดได้ที่ desktop, mobile portrait/landscape ไม่คลิกทะลุไปใช้พลัง
- pause หยุดทุกระบบที่กระทบเกม สลับ HUD ไม่แก้ timeScale ไม่ล้าง selection/order ไม่บังคับกล้อง

## P2 — ค่ายฝึกและทหารหลายหน้าที่

เพิ่ม **ประชิดเดิม → โล่ → พลธนู** ใช้อสูรเร็ว/ถึก/แม่ทัพเดิมทดสอบความต่าง ก่อนเพิ่มศัตรูใหม่

- ค่ายฝึกมีต้นทุน เวลา คิว จำนวนเป้าหมาย จุดรวมพล และเพดานกำลัง AI ฝึกชดเชยตามเป้าหมายเมื่อมีงบ มีสำรองแรงงาน/ทรัพยากรและเหตุผลเมื่อฝึกไม่ได้
- แยกการเสกทหารด้วยศรัทธาแบบ sandbox/พลังเทพจากการฝึกปกติ ไม่เปลี่ยนความหมายปุ่มเงียบ ๆ คนเข้าค่ายส่ง cargo ก่อน พร้อมแสดงผลต่อกำลังผลิต
- โล่ค้ำแนว พลธนูรักษาระยะหลังแนว มีกติกาสิ่งกีดขวาง/แนวยิงและสถิติที่อ่านง่าย
- XP/ระดับมาจากผลรบจริง ผู้รอดศึกมีคุณค่า เซฟและขึ้นยุคไม่ล้างประสบการณ์ ใช้ฝน/อาหารฟื้นตัวก่อน หน่วยแพทย์/ช่างสนามเพิ่มเมื่อจำเป็น

เกณฑ์รับ: กองผสมมีประโยชน์อธิบายได้ คิว/ราคา/สิ่งที่ขาดเห็นและจัดการได้ทันที ยกเลิกคิวคืนของตามกติกา ไม่หักซ้ำเมื่อโหลด/เปลี่ยน HUD และ AI เมืองทำงานต่อระหว่างฝึก/รบ

## P3 — เมือง เทคโนโลยี และอุตสาหกรรม

คงเส้นทางเดิม **ชนเผ่า → เกษตรกรรม → เมืองศักดินาและการค้า → จักรวรรดิเวท** เป็นฐาน ไม่เปลี่ยนยุค 4 เป็นรถถังทันที เพิ่มแขนงโรงตีเหล็ก/เครื่องกล/ดินปืน แล้วขยายสู่อุตสาหกรรมและสมัยใหม่ผ่านเงื่อนไขที่เห็นได้ ต้องขยายข้อจำกัดยุค 1–4 ใน UI, progression, wave scaling และ save schema พร้อมกัน

- ให้ไร่ ประมง ตลาด กังหันเดิมมีบทบาทการผลิต/ขน/ใช้วัตถุดิบชัด เปิดสร้างหรืออัปเกรดผ่านเมือง แทนได้ทั้งชุดจากการเปลี่ยนฉากยุค
- วิจัยใช้เวลา ทรัพยากร อาคารและคิว ผู้เล่นเลือกลำดับ/นโยบาย AI ดำเนินงานเอง
- เริ่มจากอาหาร ไม้ แร่ศิลา ศรัทธา แยกโลหะแปรรูป/เชื้อเพลิงเมื่อมีสายผลิตและผู้ใช้จริง ไม่ถือว่าแร่ศิลาเป็นเหล็กหรือน้ำมันอัตโนมัติ
- วัดกำลังผลิต การบริโภค แรงงานและต้นทุนทหารให้เมืองรองรับกองทัพ ปรับเวฟตามกำลัง/เทคโนโลยีที่ทดสอบแล้ว

เกณฑ์รับ: พัฒนาได้โดยไม่ใช้ sandbox ของเพิ่มจากแหล่งที่อธิบายได้ มีเหตุผลสร้างเมืองต่อระหว่างศึก research/production queues คืนได้จากเซฟ

## P4 — เครื่องล้อม ดินปืน รถถัง เครื่องบิน

เรียง **เครื่องยิงหิน → ปืนใหญ่/พลปืน → รถถัง → เครื่องบิน** ตามเทคโนโลยี/โครงสร้างพื้นฐาน P3 พร้อมศัตรู/อันตรายที่ทำให้แต่ละชนิดมีบทบาท

- ทำหน่วยตามข้อมูล ลดการเพิ่มเงื่อนไข `role === 'soldier'` หลายชุด UI/คำสั่ง/เซฟใช้ร่วมกัน
- เครื่องล้อม/ปืนใหญ่มีระยะต่ำสุด ระยะยิง เวลาเตรียมและลูกหลงที่อ่านได้ รถถังมีขนาด/รัศมีเลี้ยว ทางลาด ข้อจำกัดสะพาน ต้องมี routing พาหนะก่อนใช้จริง
- โรงงานผลิต ช่างซ่อม กระสุน/เชื้อเพลิงเพิ่มตามความจำเป็น AI เติม/ซ่อมภายใต้นโยบาย ไม่ต้องคลิกบริการทีละคัน
- เครื่องบินมีสนามบิน ขอบเขตการบิน เป้าหมายภาคพื้น/อากาศ ปฏิบัติการและกลับฐาน มีการป้องกันอากาศยานตอบโต้ ไม่บินวนบังฉากโดยไม่มีงาน

เกณฑ์รับ: ยานไม่ข้ามสิ่งกีดขวาง/สะพานแคบกว่าตัวเอง เครื่องบินคืนฐานรับบริการจริง กองผสมมีการตอบโต้ ไม่ให้หน่วยใหม่แทนทุกประเภท

## P5 — เรือและพื้นที่น้ำรองรับสงคราม

เรือที่ท่าประมงปัจจุบันเป็นของตกแต่ง ไม่มี navigation/cargo/combat แม่น้ำเดิมยังไม่ใช่สมรภูมิกองเรือ

ทำพื้นที่น้ำต่อเนื่องที่แล่นถึงกันได้ ท่าเรือ ขนาดทางน้ำ เส้นทาง/การหลบกัน การขนถ่าย และเหตุผลเชิงยุทธศาสตร์ก่อน เริ่ม **ขนส่ง → ลาดตระเวน → เรือรบ** การข้ามช่องว่างอากาศระหว่างเกาะใช้ระบบขนส่งทางอากาศแยกจากเรือในน้ำ

เกณฑ์รับ: เรือมีภารกิจและฝั่ง/ท่า/ศัตรูให้ปฏิสัมพันธ์ AI แล่น/ขนถ่ายจริง หากยังไม่มีพื้นที่เหมาะสมให้คงหลังระบบบก/อากาศ

## ภาพ ความสมจริง และประสิทธิภาพ

ปรับภาพทุกชุด: เงาร่างหน่วยชัด แนวรับ/ระยะโจมตีอ่านได้ แสงกลางคืนเห็นการเล่น เสียงสัมพันธ์กับปะทะ และรักษาพื้นที่ฉากจาก HUD

ย้าย custom WebGL ไป Three.js จริงเป็น spike ใน branch แยกหลังขอบเขต simulation/renderer ของ P0 เริ่มนิ่ง ก่อนขยาย asset ยานจำนวนมาก ไม่บล็อก P1 ด้วยการเขียนกราฟิกใหม่ทั้งเกม เทียบมุมเดียวกันของ terrain/บ้าน/คน/ป้อม/พลัง/การเลือกวัตถุ แล้วจึงย้ายทั้งโลก ใช้ GLB/PBR/animation และสิทธิ์ asset ชัดเจนตาม [ARCHITECTURE.md](ARCHITECTURE.md)

วัด CPU/GPU, frame time, draw calls, จำนวนหน่วย/อสูร/กระสุน และ memory หลังโหลด/เปลี่ยนโลก ทำ spatial lookup/formation budget ก่อนกองทัพขนาดใหญ่ เป้าหมาย 60fps desktop/30fps mobile ต้องวัดเครื่องจริง ไม่ใช่ผล software WebGL รอบนี้

## ชุดพัฒนาถัดไป

เริ่ม **P0a: เมืองไม่ถูกล้างเมื่อขึ้นยุค + ความเร็วไม่สั่งขึ้นยุค + ข้อมูลตัวตน** แล้วต่อ **P1: สั่งทหารเดิม + HUD เมือง/รบ + AI ปลอดภัยตามพื้นที่** พร้อม **P0b: เซฟโลกต่อเนื่อง** ให้ครบก่อนเพิ่มทหารใหม่/XP/วิจัย

จุดตรวจปลาย P0b + P1: สั่งตัดไม้ → สร้างป้อม → รวมพลรักษาสะพาน → อสูรบุก/HUD เปลี่ยน → AI ส่งของในพื้นที่ปลอดภัย → ถอยและใช้ฝนช่วย → หลังศึกกลับงาน/ซ่อมเมือง → save/reload แล้วลงทุนต่อจากเมืองเดิม

ทุกชุดมี simulation test ที่มีความหมาย ภาพ desktop/mobile และการทดลอง UI จริง แยก controlled fixture จากการเล่นต่อเนื่อง ใช้ผู้เล่นทดลองก่อนล็อกสมดุลระยะยาว
