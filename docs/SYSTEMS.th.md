# บัญชีระบบเดิมของ AETHERIA

> บัญชีนี้อธิบายระบบต้นฉบับและการสำรวจช่วงแรก สำหรับสถานะโค้ดล่าสุดวันที่ 18 ต.ค. 2026 ดู [CURRENT_REVIEW.th.md](CURRENT_REVIEW.th.md) ซึ่งรวมคำสั่งคนงาน/UI/การต่อสู้ที่เพิ่มภายหลัง และการถอดบอลลูน/เรือเหาะตกแต่งออกจากฉากแล้ว

เอกสารนี้เริ่มจากการไล่ระบบเดิมและตามเล่นผ่านหน้าเกม ใช้แยกสิ่งที่มีอยู่แล้วออกจากข้อเสนอเพิ่มงาน ไม่ควรตีความการมีโค้ดเป็นหลักฐานว่าทุกเส้นทางเล่นผ่านแล้ว หลักฐานการเล่นและขอบเขตอยู่ใน `PLAYTHROUGH.th.md`

## ระบบที่มีอยู่แล้ว

| ระบบ | กลไกที่พบในเกมเดิม | ความเชื่อมโยงที่ต้องประเมิน |
|---|---|---|
| เกาะ procedural | noise, หน้าผา, แม่น้ำ, น้ำตก, ถนน, พื้นเกาะและด้านล่าง | ความสูง/ความลาดชันมีผลต่อเดินและวางอาคาร |
| ปั้นภูมิประเทศ | ยก/ลด ปรับรัศมี ใช้ศรัทธา กันฐานอาคารและบางส่วนของแม่น้ำ ปรับระดับวัตถุตามพื้น | อาจเสียต้นไม้เมื่อพื้นไม่เหมาะสม ไม่ใช่เพียง visual deformation |
| ป่าและแร่ | ต้นไม้หลายชนิด การเติบโต ผลไม้ ปริมาณไม้และแร่ | แรงงานใช้เป็นเป้าหมายและหิวแล้วหาอาหารจากต้นไม้ |
| แรงงานและการขน | เก็บไม้/แร่แล้วแบกกลับคลังกลาง | ของที่เก็บยังไม่เข้าคลังจนเดินกลับถึง งานหาอาหาร/ก่อสร้างอาจแทรกงานขน |
| บ้านและความจุ | บ้านเพิ่มจำนวนคนที่รองรับได้; ใช้ศรัทธาเสกคนเพิ่ม | จำนวนคนและกำลังงานสัมพันธ์กับจำนวนบ้าน |
| ก่อสร้างอัตโนมัติ | เมืองตัดสินใจบ้าน/ป้อมจากยุค จำนวนสิ่งปลูกสร้าง และทรัพยากร; แรงงานต้องเดินไปสร้างต่อ | มีทั้งการจ่ายต้นทุนเริ่มงานและ progress อาคาร ไม่ใช่ spawn อาคารอย่างเดียว |
| ซ่อมอาคาร | แรงงานหาอาคารเสียหายหลังงานก่อสร้าง | เงื่อนไขทรัพยากรและลำดับความสำคัญของงานมีผลต่อแนวป้องกัน |
| ความหิวและ HP | ทุกคนหิวเพิ่ม; พลเรือนหาอาหาร/ผลไม้ ขาดอาหารหนักแล้วเสีย HP | แทรกงานผลิต/ขน/สร้าง การลดความหิวด้วยพรทำให้งานเมืองกลับมาเดิน |
| อาชีพ 6 แบบ | villager, soldier, child, farmer, fisherman, merchant | เกษตร/ประมงเพิ่มอาหาร พ่อค้าเพิ่มศรัทธา เด็กวิ่งเล่น ทหารป้องกัน; อาชีพเพิ่มตามยุค |
| เดินทางและหลบสิ่งกีดขวาง | ข้ามแม่น้ำผ่านสะพาน หลบอาคาร/ยูนิต ตรวจความสูง | ต้องแยกการเดินอ้อมตามกติกาจากการติดทางจริงด้วยตำแหน่งต่อเนื่อง |
| ศรัทธา | ฟื้นตามเวลา ได้จากบางงาน/การค้าหรือเหตุการณ์/การสังหาร/รุ่งอรุณ/คนอยู่ในที่พัก | ใช้แข่งขันกันระหว่างเสกคน แต่งตั้งทหาร พลังโจมตี ฝน และพรป้อม |
| กลางวัน–กลางคืน | นาฬิกา วัน แสง/ท้องฟ้า กลางคืนพลเรือนกลับบ้าน ทหารออกหน้า | คืนเปลี่ยนพฤติกรรมเมืองจริง ไม่ใช่เปลี่ยนสีฉาก |
| ทหาร | ลาดตระเวน ตั้งแนว เผชิญศัตรู โจมตีระยะประชิด และกินเพื่อฟื้น | การแต่งตั้งเปลี่ยนแรงงานเดิมเป็นทหาร มีผลต่อกำลังผลิต |
| ป้อม | อาคารมี progress, HP, ระยะยิง, fire cooldown, กระสุนติดตามเป้าหมาย | ต้องเสร็จก่อนยิง ป้องกันได้ตามตำแหน่ง |
| อสูรและเวฟ | คลื่นแรกตอนกลางคืน คลื่นหนุนหลังเที่ยงคืน ระดับตามวัน/ยุค มี Shadow Stalker (เร็ว), Siege Brute (ถึก), Void Overlord (แม่ทัพ) อยู่แล้ว | เลือกเป้าจากยูนิตและอาคาร แสงกลางวันทำความเสียหายต่ออสูร |
| วิหาร | HP ตามยุค; เมื่อหมดเลือดฟื้นบางส่วนและสะท้อนศัตรู | เป็นกติกาคุ้มครองเมืองที่มีอยู่แล้ว ต้องถามเจตนาก่อนเปลี่ยนเป็นโหมดแพ้ |
| พลังฝน | เพิ่มอาหาร เร่งต้นไม้/ผลไม้ ปลูกต้นใหม่บางตำแหน่ง ฟื้น HP/ลดหิวใกล้พื้นที่ | สนับสนุนเศรษฐกิจและการอยู่รอด |
| อุกกาบาต | projectile, AoE damage, หลุมพื้นดิน, ทำลายต้นไม้ และมีลูกหลงคน/อาคาร | การเล็งเลือกตำแหน่งมีต้นทุนจริง |
| สายฟ้า | ทำความเสียหายอสูรในรัศมี กระทบต้นไม้และคนใกล้จุดผ่า | ใช้ต่างจากอุกกาบาตและต่างจากตัวเลือกสายฟ้าในหน้าต่างเหตุการณ์ |
| พรลำแสง | วางป้อมในที่เหมาะสมและฟื้นคนทั้งหมู่บ้าน | ผู้เล่นมีการเลือกตำแหน่งป้อมอยู่แล้ว ไม่ควรเสนอ placement เป็นของใหม่ทั้งชุด |
| พัฒนา 4 ยุค | progress จากเวลา/บางเหตุการณ์, ปุ่มพัฒนา, auto-advance ที่ 5x และปุ่มเลือกยุคโดยตรง | เปลี่ยนทั้งรูปแบบเมือง อาชีพ ประชากร สิ่งปลูกสร้าง และการป้องกัน |
| เหตุการณ์ 5 กลุ่ม | เสบียง, สภา, คาราวาน, ศิลา, การทหาร กลุ่มละ 3 ทางเลือก | มีต้นทุน ผลประโยชน์ และบางข้อมีความเสี่ยงอยู่แล้ว; แท็บดูฉากและปุ่มเรียกเหตุการณ์มีให้ใน UI |
| NPC และเรื่องเล่า | thought bubbles, คำบ่น/คำขอบคุณ, inspector แสดงงาน/หิว/HP/แผน | ช่วยให้เห็นสาเหตุของพฤติกรรม แต่ต้องตรวจข้อความกับผลจริง |
| การดูเมือง | orbit/pan/zoom, keyboard, reset, follow NPC/asset, jump battle, minimap และ jump จาก minimap | เป็นเครื่องมือเล่นและวินิจฉัย ไม่ควรตัดสินจากกล้องเริ่มต้นมุมเดียว |
| HUD | พับการ์ด ซ่อนแต่ละด้าน ซ่อนทั้งหมด ซ่อน speech bubbles และจัดแผงมือถือ | ผู้เล่นลดสิ่งบดบังสนามได้อยู่แล้ว |
| ชีวิตในฉาก | รถม้า ม้ากับแกะ กังหัน เรือ บอลลูน เรือเหาะ น้ำตก ดวงดาว | รถม้า/สัตว์มีเส้นทางและ animation แต่ยังไม่พบ inventory สินค้า/ระบบปศุสัตว์ผลิตของจากโค้ดที่ตรวจ |
| เสียงสังเคราะห์ | ลม น้ำ กระดิ่ง ฟ้าร้อง เสียงทำงาน/พร และ volume แยก | ต้องมี user gesture เพื่อเริ่ม AudioContext; การรัน headless ไม่เท่ากับฟังคุณภาพเสียงจริง |
| ภาพเหตุการณ์ | ฉาก 2D procedural/ภาพฝังในไฟล์ สลับภาพและนำเข้าภาพเอง | แยกคุณภาพภาพเหตุการณ์ออกจากคุณภาพโลก 3D |
| บันทึกความก้าวหน้า | localStorage V1 เก็บวัน เวลา ทรัพยากร ยุคและ progress | มีระบบเซฟอยู่แล้ว แต่ยังไม่ใช่ full world snapshot |

## รายการเหตุการณ์และผลที่มีอยู่แล้ว

| กลุ่ม | ทางเลือก 1 | ทางเลือก 2 | ทางเลือก 3 |
|---|---|---|---|
| เสบียง | ศรัทธา 15 → อาหาร 35, คนอิ่ม/ฟื้น, progress +15 | ไม้ 10 → อาหาร 22, ลดหิว | ได้ไม้ 25 + แร่ 20 แต่พลเรือนเสีย HP |
| สภา | ไม้ 15 → พยายามวางบ้าน + คน 2 | แร่ 15 → พยายามวางป้อม + ทหาร 2 | ศรัทธา 25 → คน 1 + ทหาร 1 + progress 20 |
| คาราวาน | ศรัทธา 15 → รถม้า + อาหาร 30 | ไม้ 15 → แร่ 35 + ศรัทธา 35 | อาหาร 20 → ทหาร 2 |
| ศิลา | ศรัทธา 55 + progress 18 | แร่ 35 + ไม้ 30 + อาหาร 20 | ศรัทธา 80 + progress 30 แต่เกิดอสูร 2 |
| การทหาร | ศรัทธา 15 → ผ่าอสูรทุกตัว -160HP + ฟื้นทหาร | แร่ 12 → เพิ่ม Max HP อาคาร 50 และซ่อม/สร้างเสร็จ | ศรัทธา +45 |

ตัวเลขในตารางอ่านจากโค้ดเดิม ไม่ได้หมายความว่าได้ทดลองผลทุกข้อครบแล้ว เช่น ตัวเลือกสร้างบ้าน/ป้อมมีการหาที่ว่างจำกัดครั้ง ถ้าหาที่ไม่ได้ควรตรวจว่าข้อความผลลัพธ์ยังอ้างว่าสร้างแล้วหรือไม่ แยกเป็นประเด็นที่ต้องทดสอบ ไม่สรุปว่าเกิดทุกครั้ง
