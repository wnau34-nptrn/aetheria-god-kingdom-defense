# กองทัพ RTS และ HUD เมือง/สนามรบ

> วิธีเล่นหลักเปลี่ยนเป็น [การตัดสินใจตามสถานการณ์](STRATEGIC_DECISIONS.th.md) แล้ว AI เลือกคน/กองทัพ/เป้าหมายเอง ขั้นตอนเลือกหน่วยและแตะตำแหน่งในเอกสารนี้ใช้เมื่อเปิด **เมนู → รูปแบบการบัญชาการ → ควบคุมยูนิตโดยตรง** เท่านั้น เป็นบันทึกกลไกเดิมที่ยังใช้ต่อได้


P1 ขั้นแรกใช้ทหารประชิดและอสูรเดิม เพิ่มคำสั่งและการรับมือภัยใน simulation เดียวกับเมือง ไม่ได้เพิ่มค่ายฝึก ทหารประเภทใหม่ หรือยานรบในรุ่นนี้

## วิธีใช้

กด **เลือกทั้งกอง** บน HUD หรือเลือกทหารบนเกาะ เมาส์ใช้ Shift + คลิกเพื่อเพิ่ม/เอาหน่วยออกจากกลุ่ม ลากหมุนกล้องได้โดยไม่เปลี่ยนกลุ่มที่เลือก สัมผัสใช้การแตะเลือกและแตะจุดหมาย

| คำสั่ง | พฤติกรรม |
|---|---|
| รวมพลที่เมือง | เดินกลับจุดรวมใกล้ฐาน แล้วป้องกันบริเวณนั้น |
| เคลื่อนพล | กดแล้วแตะพื้น เดินไปจุดหมายก่อนรับมือศัตรูใกล้จุด |
| ตั้งรับตรงนี้ | แตะจุดรับผิดชอบ เข้าปะทะในระยะจำกัดแล้วกลับประจำจุด |
| โจมตีพื้นที่ | เดินเข้าพื้นที่และโจมตีศัตรูใกล้ทางเดิน/จุดหมาย |
| ถอยกลับฐาน | ถอนกำลังโดยไม่หาเป้าหมายใหม่ ท่าโจมตีที่เริ่มแล้วจบครั้งเดียวก่อนถอย |
| คืน AI | ยกเลิกคำสั่งเฉพาะและกลับพฤติกรรมทหารอัตโนมัติเดิม |

คำสั่งไม่เสียทรัพยากร มีวงเลือก จุดหมาย และสถานะตอบรับ แต่ละหน่วยได้ตำแหน่งแยกกัน หากจัดตำแหน่งไม่ได้จะไม่เปลี่ยนคำสั่งของทั้งกลุ่ม ยกเลิกการเล็งด้วยปุ่มยกเลิก/Escape หรือเลือกพลังเทพ

## HUD และกล้อง

**อัตโนมัติ** แสดงเมืองยามสงบและแสดงแถบรบเมื่อเตรียมบุก มีอสูร หรือรอทัพหนุน ใช้ภัยจริงรวมอสูรกลางวันด้วย ไม่จบศึกเพียงเพราะรุ่งเช้า ช่วงหลังศึกแสดงจำนวนทหาร/อาคารที่สูญเสีย แล้วกลับเน้นเมือง ผู้เล่นเลือก **เมือง / รบ** ค้างไว้ได้เอง

สลับ HUD ไม่หยุดเวลา ไม่ล้างงาน/คำสั่ง และไม่ย้ายกล้อง ปุ่ม **ไปจุดรบ** เน้นตำแหน่งอาคารที่กำลังถูกโจมตีหรือศัตรู มีปุ่มกลับมุมเดิม ปุ่มทหาร +1 ชาวบ้าน +1 และป้อมอยู่ในหน้ารบ งานบ้าน/พัฒนายุคเข้าจากแท็บเมืองได้ทันที

เหตุการณ์แบบการ์ดย่อในช่วงเตรียมศึก/มีภัย/รอหนุนไม่หยุด simulation ไม่ย้ายกล้อง และไม่ดึง keyboard focus คำตอบสามข้อยังอยู่ให้เลือก การเปิด **เรื่องราว** จะหยุดเกมเหมือนเดิม การ์ดเหตุการณ์ยามสงบยังใช้กติกาหยุดเวลาของรุ่นก่อน

## AI เมืองระหว่างศึก

คนงานพิจารณาภัยรอบตัวและเป้าหมายงาน พื้นที่ปลอดภัยยังเก็บ ส่งของ และสร้างได้ตอนกลางคืน ผู้ที่อยู่ใกล้อสูรหรือมีปลายทางอันตรายไปที่พัก/จุดปลอดภัย เก็บ cargo และคำสั่งเดิม รอภัยผ่านอย่างน้อย 4 วินาที simulation แล้วกลับงาน ความหิวไม่ดึงออกไปหาอาหารกลางอสูร ที่พักใช้คลังอาหารได้ถ้ามีของ

เส้นทางยังใช้ heuristic เดิมร่วมกับสะพาน การเว้นระยะ และการจัดจุดหมาย ไม่ใช่ navmesh หรือระบบจองคิวสะพานเต็มรูปแบบ ยังต้องตรวจการติดขัดเมื่อขยายจำนวนกองทัพ วงภาพใช้ pool จำกัด 32 หน่วยที่เลือกและ 8 จุดหมาย

## ตรวจสอบและขอบเขต

`tests/battle.test.js` ตรวจสถานะศึก การจัดกอง ตั้งรับ/กลับจุด ถอยระหว่างโจมตี การข้ามสะพาน งานปลอดภัย 1x/5x การหลบภัยพร้อมรักษางาน/cargo กล้อง เหตุการณ์ และการเลือกหลังยูนิตตาย

`tests/army.spec.js` กดปุ่มจริงผ่านเมาส์/สัมผัส ตรวจคำสั่งบนพื้น การหมุนกล้องโดยกลุ่มไม่เปลี่ยน กลับมุมเดิม ตอบเหตุการณ์โดยเวลาเดิน และจอ 400×300 ใช้ฉากทดสอบควบคุมตำแหน่ง/เวฟเพื่อทำซ้ำ ไม่ใช่ผลเล่นแคมเปญธรรมชาติเต็มคืน ชุด decision-layout/direct-controls/combat ตรวจการทำงานร่วมกับ UI เดิม

ใช้ Playwright + Chromium/SwiftShader เพราะรอบนี้ไม่มี Browser/CUA tool ให้เรียก ภาพและผลทดสอบยืนยันการใช้งาน ไม่ใช่ผลวัด GPU จริงหรือผลประเมินความสนุกจากผู้เล่น

**เซฟ V1 ยังไม่เก็บโลกหรือคำสั่งกองทัพ** งานถัดไปคือ World Save V2 ก่อนระบบฝึกสะสม/วิจัย อ่าน [แผนพัฒนา](ROADMAP.th.md)
