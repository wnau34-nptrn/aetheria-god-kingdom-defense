# จังหวะต่อสู้และน้ำหนักการปะทะ

การโจมตีระยะประชิดใช้กติกาใน `src/systems/combat.js` และแสดงผลด้วย `src/render/combat-view.js` โดย runtime เดิมเชื่อมการเคลื่อนที่ ความเสียหาย รางวัล และการทำลายอาคาร

## พฤติกรรม

- เดินเข้าระยะอาวุธแล้วหยุดตั้งหลัก ระหว่างง้าง ฟัน และคืนท่าจะไม่ไล่เดินทะลุเป้าหมาย
- จังหวะกระทบเกิดกลางช่วงฟัน ใช้ความเสียหายได้ครั้งเดียวต่อรอบ เป้าหมายที่ออกนอกระยะหรืออ้อมไปด้านหลังหลบการฟันที่ออกไปแล้วได้
- ยึดเป้าหมายเดิมขณะยังมีชีวิตและเข้าถึงได้ในรายการเป้าหมาย เมื่อเป้าหมายตายหรือเข้าบ้านจะเลือกใหม่
- ทหารใช้รอบโจมตี 0.45 วินาทีเกม อสูรใช้ 0.85 วินาทีเกมตามอัตราเดิม โดยตัวเร็ว ตัวถึก และบอสมีสัดส่วนง้าง/ฟัน/คืนท่าต่างกัน
- แก้การทับกันของพื้นที่ยืนทั้งฝ่ายเดียวกันและคนละฝ่ายอย่างค่อยเป็นค่อยไป ตรวจพื้นดิน แม่น้ำ สะพาน และฐานอาคารก่อนขยับ ไม่มีการผลักกระเด็นผ่านภูมิประเทศ
- ท่าต่อสู้หยุดการเด้งลำตัวแบบเดิม มีการตั้งขา ยกอาวุธ และเอนตัวตามช่วงโจมตี
- เมื่อโดนโจมตีมีการสะดุ้งภาพตัวละคร สีสะท้อนชั่วครู่ ประกาย ตัวเลขความเสียหาย และหลอดเลือดเฉพาะระหว่างปะทะ/เพิ่งโดนโจมตี/ถูกเลือก เอฟเฟกต์รับแรงไม่เปลี่ยนพิกัดจำลอง
- เมื่อพ่ายแพ้จะถูกถอดจากเป้าหมายและการนับยูนิตทันที ภาพตัวละครล้มลงก่อนค่อยยุบหายภายใน 1.2 วินาทีเกม ไม่ให้รางวัลซ้ำ
- กระสุนป้อม สายฟ้า อุกกาบาต และพลังโจมตีจากเหตุการณ์ใช้การตอบสนองเมื่อโดนโจมตีเดียวกัน ระบบเกราะวิหารยังทำงาน
- กดพักหรือเปิดเรื่องราวเหตุการณ์แล้วจังหวะฟัน เลือด ปฏิกิริยา และท่าล้มหยุดตาม simulation ความเร็ว 1×–5× ใช้กติกาเดียวกัน

## ขอบเขตภาพและเสียง

ประกายกระทบใช้กลุ่มที่เตรียมไว้สูงสุด 12 กลุ่ม ตัวเลขสูงสุด 16 รายการ และภาพตัวละครที่ล้มสูงสุด 16 ตัว หลอดเลือดปรับขนาดตามภาพยูนิต เมื่อซูมไกลจะซ่อนตัวเลขความเสียหายเพื่อไม่ให้ทับกัน Canvas ของเลือด/ตัวเลขไม่รับ pointer และอยู่ใต้ HUD การเปลี่ยนยุคหรือเกาะล้างภาพค้างและคืนค่าวัสดุ

เสียงเหวี่ยงเกิดต้นช่วงฟัน เสียงกระทบเกิดตอนลดเลือด แยกเสียงเกราะและแรงกระแทกหนัก พร้อมเสียงล้ม จำกัดเสียงพร้อมกัน 10 เสียงและเว้นระยะเสียงชนิดเดียวกัน ไม่ใช้เสียงทำงานแทนการฟันอีกต่อไป

## การตรวจสอบ

`combat.test.js` ตรวจเวลาที่กระทบ การฟันไม่ซ้ำ การหลบระยะ/อ้อมหลัง เป้าหมาย การยืน การหยุดเวลา ท่าตาย เกราะวิหาร และขอบเขตเอฟเฟกต์ ชุดความเร็วเดิมตรวจความเท่ากันของผลจำลอง 1×/2.5×/5×

`combat.spec.js` มีฉากควบคุมการดวลและกลุ่มบนหน้าจอ touch พร้อมภาพง้าง/กระทบ/ล้ม และการบุกกลางคืนจากเมืองเริ่มต้นผ่านปุ่มผู้เล่นจริง ฉากควบคุมใช้เพื่อแยกตรวจภาพ ไม่ใช้แทนหลักฐานความสมดุลหรือความสนุกของเกม

ผล WebGL แบบ software ใช้ยืนยันพฤติกรรมและภาพ ไม่ใช่ผลวัด FPS เครื่องจริง การประเมินความรู้สึกและความสมดุลยังต้องอาศัยการเล่นต่อเนื่อง
