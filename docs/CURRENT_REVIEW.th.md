# ผลตรวจเกมปัจจุบันเพื่อปรับแผนพัฒนา

ตรวจวันที่ **18 ตุลาคม 2026** ฐานเกม `7bd3f97beb381e4b24ca5550eb981727c1db5465` ตรงกับ remote main ก่อนแก้เอกสาร รอบนี้เปลี่ยนแผนและเอกสาร ไม่ได้เพิ่มระบบ RTS/ฝึกทหาร/ยานรบลงเกม ดู [แผนที่ปรับแล้ว](ROADMAP.th.md)

## ข้อค้นพบที่เปลี่ยนลำดับงาน

1. **ขึ้นยุคแล้วเมืองกับคนถูกสร้างใหม่** `evolveToEra()` เรียก `populateWorld()` ซึ่งล้าง agents/buildings/monsters/projectiles แล้วสร้างชุดของยุคนั้น การทดลองยืนยันว่าคนและบ้านเดิมไม่อยู่ใน arrays แล้ว แต่ต้นไม้เดิมยังอยู่เมื่อไม่ได้ regenerate ธรรมชาติ XP การฝึกและการลงทุนระยะยาวต้องรอแก้ความต่อเนื่องนี้
2. **5x มีผลต่อ progression นอกเหนือจากเร่งเวลา** เมื่อ progress เต็ม `updateSimulation()` ขึ้นยุคเองเฉพาะเมื่อ timeScale >= 5 การทดลองตั้ง progress 99.99 แล้วเดิน simulation ที่ 5x ยืนยันว่าขึ้นยุค 2 ต้องแยกการเร่งเวลาออกจากคำสั่งพัฒนายุค
3. **เซฟยังเป็น checkpoint เก้าฟิลด์** ไม่มีตำแหน่งคน อาคารที่สร้าง HP ภูมิประเทศ งาน cargo เวฟ หรือ RNG ไม่สามารถใช้รับรองความต่อเนื่องของเมือง/กองทัพได้
4. **AI พลเรือนหยุดงานทั้งเกาะตอนกลางคืน** การทดลองกลางคืนที่ไม่มีศัตรูพบพลเรือนห้าคนอยู่ SHELTER ทหารสองคน NIGHT_DEFENSE กลับกลางวันแล้วทำงานต่อ จึงต้องเปลี่ยนเป็นความปลอดภัยตามพื้นที่เพื่อให้เศรษฐกิจเดินต่อระหว่างรบ ความหิวถูกตรวจเหนือการหลบภัยด้วย ต้องจัดลำดับการอยู่รอดให้สอดคล้องกัน
5. **ทหารยังเป็นประชิดชนิดเดียว ไม่มีคำสั่งกองทัพ/ค่ายฝึก** ปุ่ม “ทหาร +1” เปลี่ยน villager เป็น soldier ทันทีด้วยศรัทธา 25; ถ้าไม่มี villager จะเสกใหม่ เป็นกลไกเดิมที่ต้องแยกให้ชัดจากการฝึกแบบใช้เวลา/คิว
6. **HUD เปลี่ยนคำเตือน แต่ไม่เปลี่ยนเครื่องมือเป็นการรบ** จอ desktop/mobile มีปุ่มเมืองหกปุ่มและพลังหกช่องเดิมระหว่างการปะทะ มือถือในมุมเริ่มต้นเห็นเมืองแต่แนวรบอยู่ด้านข้างนอกจอ ต้องมีแจ้งเตือนกดไปจุดรบและกลับมุมเมือง โดยผู้เล่นคุมกล้อง
7. **ยุคเดิมเป็นแฟนตาซีสี่ยุค** ชนเผ่า → เกษตรกรรม → เมืองศักดินา/การค้า → จักรวรรดิเวท ไม่ใช่ระบบดินปืน–อุตสาหกรรมที่พร้อมใส่รถถังทันที ไม่มีโรงงาน เชื้อเพลิง สนามบิน หรือเทคโนโลยีวิจัย
8. **เรือเป็นของตกแต่งและระบบกราฟิกยังเป็น custom WebGL** ต้องทำเส้นทางน้ำ/ภารกิจเรือก่อนเรือรบ และวางการย้าย Three.js จริงแยกจากการออกคำสั่ง/AI ไม่ให้การย้ายภาพทั้งเกมบล็อกชุดเล่นได้แรก

## บัญชีระบบและสิ่งที่ควรใช้ต่อ

| ด้าน | สิ่งที่มีจริง | ช่องว่างและผลต่อแผน |
|---|---|---|
| โลก/ภูมิประเทศ | เกาะ procedural, แม่น้ำ น้ำตก ถนน สะพาน ปั้นพื้น ตรวจข้อห้ามวางอาคาร | พื้น/ตำแหน่งไม่อยู่ในเซฟ การเปลี่ยนยุคปรับ terrain ตามยุค จึงต้องตรวจผลต่อฐานอาคารและเส้นทางเดิมเมื่อเลิก reset |
| การเคลื่อนที่ | เดินอ้อมอาคาร/ยูนิต เลือกข้ามสะพาน จำกัดพื้นที่แม่น้ำ/ความสูง | ยังไม่ใช่ navigation graph ทั่วโลก ไม่มีขนาดพาหนะ/การเลี้ยว ต้องจัดคิวกองทหารและทำ vehicle routing ก่อนรถถัง |
| เศรษฐกิจ | อาหาร ไม้ แร่ศิลา ศรัทธา; เก็บจริง แบก ส่งวิหารแล้วเข้าคลัง | แร่ศิลาไม่เท่ากับโลหะ/เชื้อเพลิง ไม่มี supply chain อุตสาหกรรม |
| คำสั่งแรงงาน | เลือกคนงาน → ตัดไม้/ขุดแร่/ผลไม้/auto; หาแหล่งใหม่เอง เก็บ workOrder/cargo ระหว่างพัก | งานสั่งเฉพาะไม่รับงานสร้าง/ซ่อมทั่วไป ต้องมีนโยบายแรงงานสำรองเมื่อขยายเมือง/ค่ายฝึก |
| อาชีพ | villager, farmer, fisherman, merchant, child, soldier | farmer/fisherman ขนอาหาร merchant เพิ่มศรัทธา ไม่มี UI ฝึก/เปลี่ยนอาชีพครบทุกแบบ |
| ก่อสร้าง/ซ่อม | บ้าน/ป้อมเลือกจุดและยืนยัน คนงานเดินไปสร้าง มี progress/HP และซ่อมอัตโนมัติ; autoBuild เปิดได้แต่ค่าเริ่มต้นปิด | ผลิตอาหาร/ตลาด/กังหันได้จากชุดยุค ยังสร้างเองไม่ได้ครบ ไม่มีค่ายฝึก/โรงงาน ควรต่อจาก placement เดิม |
| ประชากร/ความหิว | ความจุบ้าน ความหิว หาอาหาร พักพิง อดอาหารเสีย HP | ฝึกทหารดึงแรงงานออกจริง ต้องแสดงผลต่อกำลังผลิต/สำรองแรงงาน; หลบภัยตามเวลายังหยุดทุกอาชีพ |
| ศรัทธา/พลังเทพ | ฟื้นพื้นฐาน + งาน/การค้า/ศึก/เหตุการณ์; ฝน ปั้นพื้น อุกกาบาต สายฟ้า พรสร้างป้อม | หลายระบบแข่งขันใช้ศรัทธา ราคา/ผลแตกต่างกัน พรป้อมและการสร้างป้อมด้วยคนงานเป็นสองเส้นทางที่มีแล้ว |
| ทหาร/การปะทะ | ประชิดหนึ่งชนิด เตรียม–ปะทะ–คืนท่า เลือด/เสียง/แรงสะท้อน/ล้มตาย ตั้งแถวกลางคืน/ลาดตระเวนอัตโนมัติ | ไม่มี select group/order/hold radius/retreat/XP; กลางคืนไล่ศัตรูทั่วเกาะ ต้องให้คำสั่งผู้เล่นมีลำดับเหนือ AI เดิม |
| ป้อม/อสูร | ป้อมยิงกระสุนอัตโนมัติ อสูรเร็ว/ถึก/แม่ทัพ เลือกเป้าหมายและตีคน/อาคาร | ใช้ศัตรูเดิมเป็นฐานทดสอบทหารหลายชนิดก่อนเพิ่มศัตรูใหม่ กฎเป้าหมาย/แนวยิงต้องรองรับหน่วยระยะไกล |
| เวฟ/วิหาร | เวฟแรก 20:00 ทัพหนุนหลัง 00:30 แสงเริ่มเผาอสูร 05:30; วิหารฟื้น 65%/สะท้อนเมื่อเลือดหมด | ไม่ใช่โหมดแพ้ถาวร HUD ต้องแยกไม่มีศัตรูชั่วคราว/รอทัพหนุน/ศึกจบจริง ไม่ผูก combat กับกลางคืนอย่างเดียว |
| เหตุการณ์ | ห้ากลุ่ม กลุ่มละสามคำตอบ ราคา/ผลชัด เก็บคำถามไว้เล่นต่อได้ มีต้นทุน/ความเสี่ยง/รางวัล | เปิดเหตุการณ์ใหม่ยัง pause และย้ายกล้อง แม้การ์ดย่อ ต้องปรับจังหวะแทรกในศึก; คาราวานให้โบนัสทันที ไม่ใช่ cargo ของรถม้า |
| ยุค/ความก้าวหน้า | สี่ยุค มี progress ตามเวลา/เหตุการณ์ เพิ่มอาชีพ อาคาร ประชากร และป้อม | ชุดฉากยุคแทนการอัปเกรดเมืองเดิม ยังไม่มี research tree/คิว/อาคารปลดล็อก ต้องแยก sandbox จาก progression |
| กล้อง/แผนที่/ข้อมูล | หมุน/เลื่อน/ซูม รีเซ็ต ติดตาม NPC แผนที่ย่อ jump battle ข้อมูล HP/งาน | ใช้ปุ่ม jump battle เดิมต่อยอดแจ้งภัยเฉพาะจุด การสั่งพื้นต้องไม่ชนการหมุนกล้อง/เล็งพลัง |
| HUD/สัมผัส | คำสั่งเมืองหกปุ่ม แถบทรัพยากร พลัง แผงข้อมูลตามต้องการ คำตอบเหตุการณ์ทันที รองรับ portrait/landscape | ยังไม่มีหน้ารบ/สถานะวิหารหลัก/กองที่เลือก/คำสั่งทหาร; ห้ามเพิ่มทุกปุ่มเป็นแถวถาวรจนบังสนาม |
| สิ่งมีชีวิต/ยานฉาก | รถม้าเดินตาม waypoint สัตว์เดินในคอก กังหันหมุน เรือโยกบนผิวน้ำ | ยังไม่มี cargo รถม้า/ผลิตภัณฑ์ปศุสัตว์/การรบทางน้ำ; บอลลูนและเรือเหาะตกแต่งถูกถอดจากฉากแล้ว แต่เรื่องเล่าคาราวานยังอยู่ |
| เวลา/สถาปัตยกรรม | fixed-step 50ms แยก helper เศรษฐกิจ/คำสั่ง/ต่อสู้จาก runtime บางส่วน | runtime หลักยังผูก arrays/mesh/DOM; บาง event/visual timer ใช้เวลาภาพ ขอบเขตนี้ต้องระบุเมื่อทำเซฟ/ทดสอบเวลา |
| กราฟิก/เสียง/ประสิทธิภาพ | custom renderer, procedural meshes, เสียงสังเคราะห์ ปะทะมี effect pool จำกัด | ไม่มีแพ็กเกจ three/GLB pipeline จริง มี render scheduling 42ms + RAF ต้องวัดจริงก่อนสัญญา 60fps/กองทัพใหญ่ |
| บันทึก/เผยแพร่ | V1 ตรวจค่าเซฟ มี unit/browser/production smoke และ CI deploy Pages/ตรวจ SHA | ไม่มี full snapshot/autosave; pipeline มีแล้ว ไม่ต้องทำการนำขึ้น GitHub ใหม่ |

## ขอบเขตหลักฐานรอบนี้

- ไล่ runtime, economy/input/UI/combat/save modules, HTML/CSS, test harness/ข้อกำหนดทดสอบ, CI และเอกสารเดิม แยกเอกสารประวัติออกจากสถานะโค้ดล่าสุด
- ทดลอง integration แบบ seed คงที่ครบสี่ยุค ตรวจ object identity ก่อน/หลังขึ้นยุค งานกลางวัน/กลางคืนปลอดศัตรู กลับกลางวัน เงื่อนไข auto-advance 5x และชื่อฟิลด์เซฟ renderer/audio ถูก stub ในวิธีนี้
- เปิดเกม WebGL จริงด้วย Playwright ที่ 1366×900 และ touch viewport 390×844 จ้างทหารสองคนผ่าน HUD ใช้ **เครื่องมือ sandbox ข้ามไปกลางคืน** แล้วเดิน AI จนมี contact จริง เก็บภาพเมือง/รบทั้งสองจอ และการ์ดเหตุการณ์บน desktop การทดลองนี้ไม่ใช่การเล่นธรรมชาติครบวันหรือการทดสอบเครื่องมือถือจริง
- ตรวจภาพพบ UI เมืองยังอยู่ระหว่างศึกและแนวรบอยู่นอกจอมือถือในมุมเริ่มต้น ภาพเป็นหลักฐานความอ่านง่าย ไม่ใช่ผลวัด FPS/GPU หรือการประเมินความสนุกกับผู้เล่นมนุษย์
- รันชุด unit/integration เดิมด้วย npm test และ production build; Node 24 รอบนี้รายงาน 12 test-file groups ให้ใช้จำนวนจาก log ไม่สับสนกับ 127 individual cases ที่ CI Node 22 ของรุ่นฐานเคยผ่าน รอบนี้ไม่ได้รัน browser suite ทั้ง 28 สถานการณ์ซ้ำ

ข้อมูลดิบและสถานะตรวจอยู่ใน [plan-review/README.md](plan-review/README.md), [simulation.json](plan-review/simulation.json) และ [browser.json](plan-review/browser.json) ภาพ/runner/log ฉบับเต็มเก็บใน workspace ของงานนี้ที่ `/workspace/attachments/aetheria-plan-review/`

## ผลต่อแผน

ลำดับใหม่คือ **รักษาเมือง/เซฟ → สั่งกองทัพและ HUD ตามภัย → ค่ายฝึก/กองผสม → เศรษฐกิจและเทคโนโลยี → เครื่องล้อม/รถถัง/เครื่องบิน → เรือพร้อมพื้นที่น้ำ** ปรับภาพ/ความอ่านง่ายต่อเนื่อง และทดลองย้าย Three.js จริงแยกจากงาน gameplay ดูเกณฑ์รับของแต่ละชุดใน [ROADMAP.th.md](ROADMAP.th.md)
