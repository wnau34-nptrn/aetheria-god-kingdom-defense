# คำสั่งที่เข้าถึงได้ทันที

> วิธีเล่นหลักเปลี่ยนเป็น [การตัดสินใจตามสถานการณ์](STRATEGIC_DECISIONS.th.md) แล้ว AI เลือกคน/กองทัพ/เป้าหมายเอง ขั้นตอนเลือกหน่วยและแตะตำแหน่งในเอกสารนี้ใช้เมื่อเปิด **เมนู → รูปแบบการบัญชาการ → ควบคุมยูนิตโดยตรง** เท่านั้น เป็นบันทึกกลไกเดิมที่ยังใช้ต่อได้


## สิ่งที่พบและปรับ

| ระหว่างเล่น | ปัญหาเดิม | พฤติกรรมใหม่ |
|---|---|---|
| เพิ่มกำลังป้องกัน / ประชากร | ต้องเปิดอาณาจักรและเลื่อนหา | ทหาร +1 / ชาวบ้าน +1 อยู่บน HUD พร้อมราคา ยอดคนและทหารเปลี่ยนทันที |
| จัดงานคนงาน | ต้องเปิดแผงหรือเลื่อนในข้อมูลยูนิต | เลือกคนงานจาก HUD แล้วมีปุ่มงานทั้งสี่บนแถบเล่น AI หาแหล่งให้เอง |
| ก่อสร้าง | ต้องเปิดอาณาจักรก่อน | บ้าน / ป้อมอยู่บน HUD เลือกจุดและยืนยันก่อนจ่ายตามเดิม |
| พัฒนายุค | ปุ่มอยู่ในแผงยาว | แสดงความก้าวหน้าและปุ่มบน HUD เมือง กดเมื่อ 100% เพื่อรักษาเมือง/คน/งานเดิม 5x ไม่ขึ้นยุคเอง ยุคสูงสุดมีข้อความชัดเจน |
| คำถามเหตุการณ์ | ภาพ/เรื่องราวมาก่อนคำตอบบนหน้าจอเล็ก และปิดแล้วไม่เห็นคำถามเดิม | เหตุการณ์แสดงการ์ดพร้อมคำตอบสามข้อ ราคา ผลลัพธ์ และความเสี่ยงทันที |
| เล่นต่อโดยยังไม่ตอบ | คำถามเดิมหายและเปิดใหม่ได้คนละเรื่อง | เล่นต่อได้โดยเก็บคำถามเดิมและคำตอบไว้ เหตุการณ์ใหม่ไม่เขียนทับคำถามค้าง |

แผนที่ บันทึก สถิติ เสียง และเครื่องมือ sandbox ยังคงอยู่ในแผงข้อมูล ส่วนที่ใช้สั่งการระหว่างเล่นอยู่บน HUD ไม่ต้องเปิดแผงเหล่านี้ก่อน ความคิดยูนิตเป็นรายละเอียดเสริมที่ขยายอ่านได้ โดยสถานะสุขภาพและปุ่มงานยังเข้าถึงตรงได้

## คำถามและเวลา

เหตุการณ์ตามเวลาในยามสงบเปิดการ์ดและหยุด simulation ให้ตัดสินใจ ระหว่างเตรียมศึก/มีภัย/รอหนุน การ์ดย่อไม่หยุดเวลา ไม่ย้ายกล้อง และไม่ดึง focus อ่าน [กองทัพ RTS และ HUD เมือง/รบ](ARMY_RTS.th.md) เลือกคำตอบแล้วกลับสู่ความเร็วเดิม กด **เล่นต่อ · เก็บคำถามไว้** หรือปุ่มความเร็วเพื่อเล่นระหว่างรอตอบได้ ปุ่ม **เรื่องราว** เปิดรายละเอียดของคำถามเดิม และกลับสู่เกมโดยเก็บคำตอบไว้บนการ์ด

คำตอบตรวจของในคลังอีกครั้งตอนกดและปรับราคา/สถานะตามงบล่าสุด การตอบภายหลังจะรักษาความเร็วที่ผู้เล่นกำลังใช้ ไม่ย้อนกลับไปความเร็วเก่า ผลที่เลือกสำเร็จใช้ได้ครั้งเดียว ถ้าสร้างอาคารจากเหตุการณ์ไม่ได้จะไม่เก็บเงินและยังเลือกทางอื่นได้ การเริ่มเกาะใหม่ล้างคำถามของเก่า

ปุ่มทหารเลือกคนงานที่ไม่ได้แบกของ เพื่อไม่ทำทรัพยากรระหว่างขนหาย หากทุกคนกำลังขนจะบอกให้รอส่งคลัง ค่าศรัทธาและกติกาการสร้างเดิมยังใช้ตามเดิม เมื่อไม่มีคนงาน ทหารยังเสกได้ตาม sandbox เดิม

ฟอนต์ไทยและตัวเลขบรรจุมากับเกมและโหลดก่อนเริ่ม runtime เพื่อให้ราคา ข้อความ และการตัดบรรทัดคงที่ข้ามระบบปฏิบัติการ โดยไม่พึ่งบริการฟอนต์ภายนอก

## หน้าจอและการตรวจสอบ

- เดสก์ท็อปใช้แถบคำสั่งแถวเดียว มือถือแนวตั้งเรียง 3 × 2 โดยไม่ต้องเลื่อนเพื่อหาปุ่ม
- เมื่อเลือกคนงาน แถบงานปรากฏตามบริบทและจัดตำแหน่งข้อมูลยูนิต/กล้องตามความสูงใหม่ทันที
- แนวนอนขนาดเล็กใช้คำสั่งขนาดกระชับ การ์ดคำถามใช้สามคอลัมน์เมื่อพื้นที่แนวตั้งน้อยหรือมีแถบงานคนงานเพิ่ม และใช้รูปแบบเดียวกันบนจอ 800×600
- ตรวจคำถามทั้ง 5 แบบ บนจอ 5 ขนาด ทั้งมี/ไม่มีคนงานที่เลือกไว้ และในกรณีงบเป็นศูนย์ เพื่อไม่ให้ราคา/เงื่อนไขดันคำตอบหลุดพื้นที่
- ชุด `direct-controls.test.js` ตรวจการหักทรัพยากร สถานะ HUD คำถามอัตโนมัติ การรอคำตอบ ราคาใหม่ ความเร็ว และการไม่ทำผลซ้ำ
- ชุด `direct-controls.spec.js` ใช้เมาส์และ touch กับเมืองเริ่มต้นจริง ตรวจจุดรับ input ของปุ่มทุกปุ่ม จ้างคน/ทหาร เลือกงานและตอบคำถาม โดยอ่าน API เพื่อยืนยันเท่านั้น
- ชุดเศรษฐกิจเดิมยังตรวจการเดิน เก็บ ขน ส่งของ และจ่ายสร้างบ้านจนเสร็จ

การทดสอบ WebGL แบบ software เป็นการยืนยัน UI และพฤติกรรม ไม่ใช่ผลวัด FPS เครื่องจริงหรือผลทดสอบความสนุกกับมนุษย์
