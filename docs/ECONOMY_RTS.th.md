# เศรษฐกิจและคำสั่งคนงาน — RTS ขั้นแรก

เป้าหมาย: ผู้เล่นเห็นว่าใครเก็บอะไร ของอยู่ที่ไหน และจ่ายอะไรเพื่อสร้างเมือง โดยใช้ AI การเดิน การหลบภัย และคนงานเดิม

## วิธีเล่น

1. แตะ **ไม้ / แร่ศิลา / อาหาร / ศรัทธา** บนแถบทรัพยากร เพื่อดูแหล่งที่มา ของในคลัง ของระหว่างขน และสถานะคนงาน
2. กด **เลือกคนงาน** หรือเปิด **อาณาจักร → เลือกคนงาน** ปุ่มนี้วนเลือกช่างเมืองที่ยังมีชีวิต ไม่เปลี่ยนอาชีพทหารหรือเด็ก
3. เลือก **เลือกต้นไม้ / เลือกก้อนแร่ / เลือกต้นผลไม้** แล้วแตะแหล่งที่ยังเก็บได้ในฉาก ใช้ขั้นตอนเดียวกันบนเมาส์และจอสัมผัส
4. คนงานทำคำสั่งนั้นในบริเวณ 18 หน่วยรอบแหล่งที่เลือก เก็บ → แบก → ส่งวิหารกลางเมือง เมื่อส่งแล้วจึงเพิ่มคลัง พร้อมข้อความ `+จำนวน · เข้าคลัง` ในฉากและรายการในบันทึก
5. **อาณาจักร → บ้าน / ป้อม** แสดงราคาไม้ 25 + แร่ 18 เลือกพื้นเกาะ ดูวงเขียว/แดง แล้วกด **ยืนยันก่อสร้าง** คนงานต้องเดินไปสร้างจนเสร็จ

การเล็งหรือยกเลิกไม่จ่ายทรัพยากร ปุ่มยืนยันตรวจตำแหน่ง จำนวนอาคารของยุค คนงาน และของในคลังอีกครั้ง จึงไม่ใช้ของที่ยังอยู่ระหว่างขน การสร้างอัตโนมัติปิดเริ่มต้น เปิดได้ด้วยช่องในแผงอาณาจักร โดยแสดงต้นทุนต่อหลัง

## กติกาทรัพยากร

| ทรัพยากร | การผลิตจากแรงงาน | เมื่อเข้าคลัง |
|---|---|---|
| ไม้ | ต้นไม้พร้อมตัด → แบกไม่เกิน 5 ต่อรอบ | ส่งถึงวิหารกลางเมือง |
| แร่ศิลา | ก้อนแร่ → แบกไม่เกิน 4 ต่อรอบ หรือเท่าที่เหลือ | ส่งถึงวิหารกลางเมือง |
| อาหาร | ผลไม้ส่วนเกิน 2 / เก็บเกี่ยว 3 / จับปลา 2 ต่อรอบ | ส่งถึงวิหารกลางเมือง |
| ศรัทธา | ฟื้นพื้นฐาน 0.45 ต่อวินาทีเกม และโบนัสจากกิจกรรมเดิม | ให้โดยตรงตามกติกาเดิม |

ฝนและเหตุการณ์ให้โบนัสเข้าคลังทันที ข้อความแหล่งอาหารระบุข้อยกเว้นนี้ ส่วนศรัทธาเป็นพลังเทพ ไม่ใช่สิ่งของที่ต้องแบก

แร่ลดตามของที่เก็บจริงและหมดได้ ไม่มีการเติมกลับขั้นต่ำ 5 เมื่อขุด ต้นไม้ที่ตัดหมดกลับเป็นต้นอ่อน รอเติบโตก่อนตัดรอบใหม่ ผลไม้ต้องมีผลสุกจริงจึงสั่งเก็บได้

## ลำดับงาน

- คนงานหิวจัดไปหาอาหารก่อน กลางคืนพักงานไปที่พัก คำสั่งและของที่แบกไม่หาย
- ของที่แบกอยู่ส่งคลังก่อนรับงานผลิตหรือก่อสร้างรอบใหม่ เปลี่ยนคำสั่งแล้วไม่ทิ้งของเดิม
- เมื่อยืนยันอาคาร มอบหมายคนงานที่ใกล้ตำแหน่งให้สร้าง หลังเสร็จกลับไปทำคำสั่งเก็บเดิม
- งานเก็บที่ผู้เล่นระบุไม่ถูกงานก่อสร้างอัตโนมัติทั่วไปแย่ง ยกเว้นคนงานที่มอบหมายให้โครงการที่ผู้เล่นยืนยัน
- แหล่งในบริเวณหมดแล้วแสดงสถานะรอ ผู้เล่นเลือกแหล่งใหม่หรือกด **งานอัตโนมัติ** ได้

## โครงสร้างและขอบเขต

- `src/systems/economy.js`: ข้อมูลทรัพยากร เงื่อนไขแหล่งผลิต สรุปคนงาน/ของขน และการส่งคลัง
- `src/ui/economy-controls.js`: คำสั่งจาก DOM การเล็ง/ยืนยันโครงการ และข้อมูล/ข้อความในฉาก
- `src/legacy/game.js`: การเดิน การเก็บของ การขนส่ง และความคืบหน้าก่อสร้างใน fixed simulation step

นี่คือคำสั่งคนงานทีละคน ยังไม่มีลากกรอบเลือกกลุ่ม สั่งทหาร หรือระบบเส้นทางใหม่ ใช้ renderer เดิม ยังไม่ใช่การย้ายไป npm Three.js ระบบเซฟ V1 ยังเก็บเฉพาะความก้าวหน้าเดิม ไม่บันทึกคำสั่ง/โลกทั้งใบ

อาหารจากแรงงานต้องเดินส่งเพิ่ม จึงมีอัตราผลิตจริงต่างจากรุ่นก่อน การทดสอบสั้นนี้ยืนยันการทำงานและความสอดคล้องระหว่างความเร็ว ไม่ใช่ข้อสรุปว่าสมดุลการบุกกลางคืนเหมาะสมแล้ว

## การตรวจสอบ

- `tests/economy.test.js`: เก็บ/ขน/ส่งไม้ แร่ ผลไม้ที่ 1× และ 5×, แร่หมด, เปลี่ยนงานแล้วรักษาของ, หิว/กลางคืน, pause, งานก่อสร้าง, ยกเลิก/ตำแหน่งผิด/ของไม่พอ, และการเปิดสร้างอัตโนมัติ
- ชุด speed เดิมยังเทียบ 1× / 2.5× / 5× รวมแรงงานเกษตรและประมง โดยนับของในคลังและของที่แบกแยกกัน
- `tests/economy.spec.js`: เล่นจากเมืองเริ่มต้นผ่านเมาส์และ touch เลือกงานไม้และแร่ ดูของระหว่างขน รอส่งจริง และจ่ายสร้างบ้านจนเสร็จ ใช้ API อ่านตำแหน่งช่วยเล็งเท่านั้น ไม่เติมของ ย้ายคน ข้ามเวลา หรือเรียกคำสั่งผ่าน API
- Desktop ใช้ 1024×640 ตอนป้อนคำสั่ง/ภาพ และ 400×300 ช่วงรอ simulation เพื่อลดต้นทุน software WebGL; touch ใช้ 390×844 ตลอด ไม่ใช่ผลวัด FPS เครื่องจริงหรือการทดสอบความสนุกกับมนุษย์
